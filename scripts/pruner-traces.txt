# The traces the Metal AV1 encoder's learned pruning trains and is tested on (scripts/train-pruner;
# BENCHMARKS "learned pruning of the analysis"). One trace a line:
#
#   <file in ~/Library/Application Support/Glass Act/traces>  <train frames>  <test frames>  <name>
#
# Train frames are a range, first-last inclusive (`train-pruner dump` takes 5 pictures spread over
# it), or a comma list of frames. Test frames are a range: `train-pruner compare` codes its first
# frames (key frames: 10 of them; streams: up to 100). The two mustn't overlap. A trace without
# its file is skipped with a warning, so this list can name traces only some Macs have.
#
# Record new ones with the Host's trace recorder (~30 s each), or for video `glassact-bench record`,
# which keeps its frame rate (BENCHMARKS "the trace recorder"). Traces are screen captures: they
# stay out of the repo (*.scap is ignored), and so do the dumps made from them.
#
# Wanted (none of these are recorded yet; content the models haven't seen helps them most):
# - video playing, full screen and in a window
# - maps, panning and zooming
# - image-heavy web pages, scrolled
# - an IDE (Xcode, VS Code), editing and scrolling code
# - native captures at other display sizes: a MacBook's (2940 x 1912, 3024 x 1964) and a 4K
#   external display (the learned pruning's 2,000-superblock floor was set on resampled 5K)
# - revisited content, for long-term references (BENCHMARKS "learned pruning of the analysis",
#   what else): switching apps (Cmd-Tab) and back, switching Spaces and back, switching browser
#   tabs, a window opened and closed over what's under it
